# 🔥 Streakly

> **Elevate Your Daily Habits & Build Unstoppable Streaks**

Streakly is an aesthetic, gamified habit tracking web application designed to help individuals cultivate consistency, visualize their daily progress, and stay motivated through streaks, achievements, and rich analytics.

---

## 🌟 Key Features

- **⚡ Interactive Onboarding**: Personalize wake-up and bedtime routines, configure core life goals, and start with your first habit in seconds.
- **📊 Dynamic Dashboard**: Real-time daily progress ring, current streak highlights, instant habit check-ins, and 7-day completion heatmaps.
- **🎯 Comprehensive Habit Management**: Create, edit, tag, filter, and archive habits by frequency, category, and time of day.
- **📅 Detailed Calendar View**: Monthly matrix and interactive day detail inspection.
- **📈 Advanced Analytics**: Completion trends, category distribution, and performance insights.
- **🏆 Gamified Achievements**: Earn badges and milestone rewards as you build consistency.
- **🎨 Ultra-Modern Themes**: Obsidian Dark, Solar Light, Midnight Violet, and Cyberpunk Neon.
- **💾 Local Persistence & Export/Import**: Full offline-first local storage support with JSON backup and demo data seeding.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:3000`.

### Production Build
```bash
npm run build
npm run preview
```
